# AJ Travels — Asset to Vehicle Category Mapping Reference

This document is the authoritative mapping reference for all static vehicle and branding assets in `travel-agency/public/assets/`.
Follow these rules strictly to prevent category mismatches (such as showing a sedan on a bus page).

## 1. Safety & Preservation Rules
- **Never overwrite or rename existing assets.**
- **Never use a car or sedan image for a bus, coach, or Tempo Traveller service.**
- **Never use a minibus or tempo traveller image for a sedan or hatchback service.**
- If a new image is added, assign it a unique, descriptive filename.
